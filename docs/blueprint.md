# **App Name**: Mestre Marmorista

## Core Features:

- Interactive Training Steps: Guide the user through three interactive steps (mini-game) to build curiosity and anticipation.
- Visual Reward System: Provide visual rewards and progress indicators at each step to enhance engagement.
- Bonus Unlocking: Unlock and display bonus content upon completion of the interactive training.
- Testimonial Display: Showcase testimonials from satisfied customers to build trust.
- Plan Selection: Present two plan options (Basic and Complete) with clear value propositions.
- IA Pattern Recognition: Employ an AI tool to allow users to assess patterns of color/texture choices on a marmorized painting based on a small user guided set of challenges.

## Style Guidelines:

- Primary color: Deep Black (#0A0A0A) for a luxurious base.
- Background color: Light Gray (#E6E6E6), desaturated from the primary, provides a subtle backdrop that doesn't distract from the content.
- Accent color: Gold (#FFD700) to highlight important elements and add a touch of elegance. Provides stark contrast to the dark background for visual interest.
- Headline font: 'Poppins' (sans-serif) ExtraBold for impactful titles.
- Body font: 'Inter' (sans-serif) Regular for readable content. Font pairing chosen to offer strong visual contrast between distinct text elements.
- Use icons and emojis to bring the steps to life. Specifically, utilize icons in steps of mini-game to aid users in choices for the last step of the game.
- Optimize the mobile experience by making each step full-screen and slide-like to provide clear progress through a guided funel.
- Incorporate smooth transitions between sections using fade-in, slide-up effects and sparkle effects to draw focus to calls to action.
